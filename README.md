# تحدي الحروف — Frontend Demo

عرض عربي RTL بلا اعتمادات خارجية للعبة فريقين على رقعة Hex من 5×5.

## التشغيل

افتح `index.html` مباشرة، أو شغّل الخادم المحلي الصغير من داخل هذا المجلد:

```powershell
node server.mjs
```

ثم افتح `http://localhost:4173`.

## الشاشات المتاحة

- البداية وطريقة اللعب
- إعداد الفريقين، الألوان، الفريق البادئ، والمؤقّت
- شاشة مدير المسابقة مع اختيار الخلية والحكم والتراجع والحفظ المحلي
- شاشة عرض منفصلة للجمهور
- شاشة هاتف الفريق وجرس أولوية الإجابة
- شاشة الفوز ومسار الفوز، مع رابط معاينة مباشر في شريط العرض التجريبي

الأسئلة والإجابات تبقى في كتاب خارجي كما تنص المواصفات؛ المنصة تدير الرقعة والحالة فقط.
